# 🏦 Bank Management System

A console-based Bank Management System built with Python featuring PIN authentication, transaction history, and file storage.

## Features

- Create Account (Savings/Current)
- View Account Details
- Deposit Amount
- Withdraw Amount (₹20,000 daily limit)
- Check Balance
- Transfer Money
- Mini Statement (Last 5 transactions)
- Change PIN
- Delete Account

## Account Details Stored

- Account Number (Auto-generated)
- Account Holder Name
- Mobile Number (10-digit validation)
- Account Type (Savings/Current)
- Balance

## Technologies Used

- Python 3.8+
- JSON for data storage
- File handling for transaction logs
- getpass for secure PIN input
